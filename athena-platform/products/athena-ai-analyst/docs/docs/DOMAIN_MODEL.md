# 3.1 Alert

## Definition

An Alert represents a security event that requires analysis.

Examples:

- Failed login attempts.
- Malware detection.
- Suspicious network traffic.
- Privilege escalation.

---

## Attributes


Alert

id

source

event_type

timestamp

severity

description

raw_data

status


---

}

5. Design Principles
Explainability

Every conclusion generated by Athena must reference evidence.

Traceability

Analysts must understand:

What Athena analyzed.
Why it reached a conclusion.
Which data influenced the result.
Extensibility

New security concepts can be added without redesigning the system.
